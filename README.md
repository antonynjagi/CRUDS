# 🧾 CRUD App – Portfolio Project

A simple **Create, Read, Update, Delete** application built using only **HTML, CSS, and Vanilla JavaScript**, using **LocalStorage** for data persistence.
This app runs completely in the browser and works perfectly on **GitHub Pages**—no backend or database required!

---

## 🔍 Features

✅ Add new users  
✅ View list of users  
✅ Edit existing user details  
✅ Delete users  
✅ Live search functionality  
✅ Responsive layout  
✅ Fully client-side (no server needed)  
✅ Easy to deploy on GitHub Pages  

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page
- **CSS3** – Styling and responsiveness
- **JavaScript (ES6+)** – Dynamic behavior and logic
- **LocalStorage API** – Store/retrieve/delete data locally in the browser
